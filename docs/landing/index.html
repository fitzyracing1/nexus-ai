How it works

Two pieces, both on your machine. Your AI client just POSTs to localhost.

1

Install

Download the bridge (one signed .exe, no Python needed), and install the Chrome extension from the Web Store.

2

Connect

The setup page opens automatically. Paste the auth token into the extension popup. Status turns green.

3

Use

Any AI that can POST JSON drives your active tab. Click, type, fill, read, screenshot, navigate — all in the tab you're already logged into.

From your terminal, agent, or script:

curl -X POST http://127.0.0.1:17777/command \
  -H "Content-Type: application/json" \
  -H "X-Auth-Token: $YOUR_TOKEN" \
  -d '{"action":"click","args":{"selector":"text=Sign In"}}'

What's in the box

A small, focused set of actions that cover almost any workflow.

click

By CSS selector, by visible text, or by (x, y) coordinates. Synthetic mouse events so React handlers fire.

type / fill

Into inputs, textareas, contenteditables. Native value setters so controlled components pick up the change.

get_text / get_html

Read what's on the page. Whole document or scoped to a selector. Truncatable.

screenshot

Full visible-tab PNG/JPEG as a data URL. Send it straight back to a vision model.

navigate

Drive any URL in the active tab. Open new tabs, switch tabs, list tabs.

wait_for / query

Wait for a selector to appear. Query and inspect matches. Built for flaky pages.

FAQ

How is this different from Playwright or browser-use?

Those spin up a fresh, headless browser with no cookies or logins. Useful for scraping. This drives the Chrome you're already in — with your Gmail open, your bank logged in, your X account active. The AI acts as you, not as a stranger.

Is my data sent anywhere?

No. The bridge binds to 127.0.0.1 only — it's not reachable from the network. The AI client is also on your machine. License checks go to Lemon Squeezy and are cached for a week.

What can the extension see?

Every tab you have open. That's what makes it useful and what makes the permission scary. You can disable the extension or stop the bridge any time — full local kill switch.

Does it work with [my AI]?

If your AI can POST JSON over HTTP, yes. We provide examples for Claude Code, OpenAI agents, Python scripts, and curl. Anything that runs locally and can do an HTTP call works.
