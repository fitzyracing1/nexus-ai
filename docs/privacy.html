Privacy Policy for Nexus AI

Effective date: November 25, 2026
Contact: Fitzyracing1@gmail.com

This policy describes how the Nexus AI Chrome extension (“the extension”) handles information. Nexus AI is a Chrome extension (version 0.2.0 and later) that connects a user-run local program, bridge.py, to the current browser tab. Starting with version 0.2.0, the extension also offers a 7-day free trial and an optional $5/month subscription processed by Stripe, not by the Chrome Web Store.

1. What Nexus AI is

Nexus AI is a local browser bridge. It does not provide a chatbot, a cloud AI, or an account. After you install it, you run bridge.py on the same computer. The extension polls that local program at http://127.0.0.1:17777 and, when you have connected with a token, carries out commands such as click, type, read, screenshot, and navigation on the current tab.

If bridge.py is not running, or you have not pasted a token, the extension does not read page content.

2. Who is responsible

The extension is published by Joshua Almeida. For privacy questions, email Fitzyracing1@gmail.com.

The developer does not operate a backend that receives your browsing data. Page content, screenshots, tokens, and tab lists are sent only to the bridge.py process you run yourself.

When you subscribe (or when the extension checks a license key you entered), the extension also talks to a license server operated for Nexus AI and to Stripe’s checkout and billing pages. That path carries subscription data only, not browsing data. See section 3.5.

3. Information the extension handles

3.1 Information you provide

Bridge auth token. You paste this into the extension popup. It is stored in Chrome’s local extension storage (chrome.storage.local) on your computer so the extension can authenticate to bridge.py. It is not synced and is not sent anywhere except to http://127.0.0.1:17777.

License key. If you subscribe, you receive a Nexus AI license key. You may paste it into the popup, or the official site may pass it to the extension after checkout. It is stored in chrome.storage.local and is sent only to the license server to check subscription status, and to Stripe’s Customer Portal when you choose “Manage billing.”

3.2 Information read from the browser when you use the bridge

Only after you connect, and only when bridge.py issues a command, the extension may collect and return to bridge.py:

  • The current tab’s URL and title, and, if requested, a list of open tabs (id, title, URL, active state, window id)
  • Visible text, HTML, or descriptions of elements on the current page
  • A screenshot of the visible area of the current tab
  • Results of click, type, fill, scroll, key-press, and wait actions (for example, which element was used)

This may include whatever happens to be on the page, such as form fields. The extension does not try to extract passwords, payment details, or personal data as a separate feature, but if those appear in the page (or in a screenshot) and a command reads that page, they would be included in what is sent to your local bridge.py.

3.3 Status and logs kept on your device

The extension stores connection status and a short recent-command log (about the last 50 entries) in chrome.storage.local so the popup can show them. It also stores the start time of your 7-day free trial and a random install identifier, in local storage and, when Chrome sync is available, in chrome.storage.sync so a reinstall on the same Chrome profile can keep the same trial window. These values are not browsing data.

3.4 What the extension does not collect

The extension does not use cookies for analytics or advertising, and does not send telemetry about the pages you visit. It does not send page content, screenshots, tokens, or tab lists to the developer or to Stripe.

3.5 Subscriptions and payments

If you start a paid subscription, Stripe collects the payment details you enter at Checkout (for example, card number, name, and email). Nexus AI does not see or store your full card number. The license server stores:

  • Your email address, as provided to Stripe at Checkout
  • Stripe customer id and subscription id
  • Your license key and subscription status (for example, trialing, active, past due, or canceled)
  • Trial and current billing-period end times
  • The install identifier the extension sent when starting Checkout, if any

Stripe’s own privacy policy applies to payment processing: https://stripe.com/privacy. The developer uses Stripe as a payment processor, not as an advertising partner.

4. How the information is used

Information is used only to carry out the extension’s single purpose: letting your local bridge.py process drive or read the current tab at your request.

The extension does not use this information for advertising, retargeting, credit, lending, or any purpose unrelated to that bridge.

5. How the information is shared

  • Your local bridge.py process. Command results are posted to http://127.0.0.1:17777/result. That program runs on your computer and is bound to localhost. What you (or a local AI you run) do with those results is under your control.
  • The developer / license server. Page content, tokens, screenshots, tab lists, and command logs are not sent to Joshua Almeida or to the license server. The license server receives only the subscription information listed in section 3.5, so it can issue a license key and confirm that a subscription is still valid.
  • Stripe. If you subscribe, payment and billing data is processed by Stripe. The extension may open Stripe Checkout or the Stripe Customer Portal in a browser tab.
  • Legal requests. Because the developer does not receive this data, there is nothing of this kind for the developer to disclose in response to a legal request. Chrome itself may handle data under Google’s policies when you use the Chrome Web Store or the browser.
  • Sale of data. User data is not sold.

Anyone who can use your computer, or who can reach 127.0.0.1:17777 and knows your token, could drive the current tab or read command results. Keep the token private, and disconnect or stop bridge.py when you are not using it.

6. Remote code and network access

All extension scripts are included in the Chrome Web Store package. The extension does not load or run remote code. Network access is used to exchange JSON with your local bridge at http://127.0.0.1:17777, and — for licensing only — with the Nexus AI license server and with Stripe.

7. Storage, retention, and deletion

  • The token, connection status, local log, license key, and trial start time are stored by Chrome on your device until you clear the extension’s data, replace them, or uninstall the extension.
  • Uninstalling the extension removes its Chrome storage data on that profile. It does not automatically cancel a Stripe subscription or delete the license server’s billing record. Use “Manage billing” in the popup to cancel, or email Fitzyracing1@gmail.com to ask that subscription records (email, Stripe customer id, license key, status) be deleted.
  • The extension does not keep a copy of page content after it has returned a command result to bridge.py, other than brief descriptions that may appear in the on-device log.

8. Children’s privacy

The extension is not directed at children under 13, and the developer does not knowingly collect personal information from children.

9. International processing

Command data stays on your computer and is not transferred by the extension to servers in other countries. If you subscribe, Stripe and the license server may process subscription data in the countries where those services operate. If you later send command data somewhere else with your own tools, that is outside this policy.

10. Changes to this policy

If this policy changes, the updated text will be posted at the same URL, with a new effective date. Material changes will also be noted in the extension’s Chrome Web Store listing when a new version is submitted.
